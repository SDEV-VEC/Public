# Task ZIP transfer

This branch contains an encrypted transfer, not the plaintext task or its key.

1. Download this branch as a ZIP and extract it.
2. Open `download.html` in a current browser.
3. Select all four `.bin` files and paste the private key supplied in your Codex chat.
4. Click **Unlock and download ZIP**. The original, checksum-verified task ZIP downloads locally.

The unlock page has no external scripts or network requests. All decryption is local.
No Python, Node, or other installation is required on the receiving computer.
The private key is deliberately absent from this repository.
