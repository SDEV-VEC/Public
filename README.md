# Encrypted task download

[Download the encrypted package](https://raw.githubusercontent.com/SDEV-VEC/Public/download-jmespath-throughput/jmespath-encrypted-download.zip)

1. Download and extract the ZIP.
2. Open `download.html` in a current browser.
3. Select all four `part-*.bin` files and paste the key supplied separately in the private conversation.
4. Click **Unlock and download ZIP**. Upload the resulting task ZIP to the submission platform.

The original task is encrypted with AES-256-GCM. The key and unencrypted task are not included in this branch. The decoder runs locally and makes no network requests.

If the direct link does not download, right-click it and choose **Save link as**.
